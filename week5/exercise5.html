Introduction¶

Regression is widely used in data mining and machine learning for predicting an output (dependent variable) for a data object given its attributes. Regression can be defined as the task of learning a target function that maps a set of attributes onto an output. In other words, regression is a supervised learning techniques that generalizes from known examples.

We will initially consider a linear regression problem with the goal of modeling the outputs, $\boldsymbol{y}=\left[y_1, y_2, \dots, y_N\right]^\top$, based on a single attribute for each of $N$ data objects, $\boldsymbol{X}=\left[x_1, x_2, \dots, x_N\right]^\top$. To do this, we consider the model $$ \begin{equation*} y_n=w_0+w_1x_n+\epsilon_n, \end{equation*} $$ where $\epsilon_n$ is residual noise, $w_0$ a constant offset and $w_1$ the linear coefficient for $x_n$. We can write an equation for the target $y_n$ for each data object as $$ \begin{aligned} y_1&=w_0+w_1x_1+\epsilon_1\\ y_2&=w_0+w_1x_2+\epsilon_2\\ &\qquad \qquad \vdots \\ y_N&=w_0+w_1x_N+\epsilon_N.\\ \end{aligned} $$

We can think of the $n$'th equation as a vector product between the fixed true weight vector, $\boldsymbol{w} = \left[ w_0 , w_1 \right]^\top$, and the modified data point, $\tilde{\boldsymbol{x}}_n = \left [ 1, x_n \right ]^\top$. We can collect all modified data points in the matrix $\tilde{\boldsymbol{X}} = \left [ \bf{1} , \boldsymbol{x} \right ]$ where $\mathbf{1} = \left[ 1, 1, \dots , 1 \right]^\top$ is a vector of $N$ ones which allows us to compactly write the equations in matrix-vector form as $$ \begin{equation*} \boldsymbol{y} = \tilde{\boldsymbol{X}} \boldsymbol{w} + \boldsymbol{\epsilon} \end{equation*} $$

Generally, in real life problems, we do not know the true coefficients generating the data. Our goal is therefore to estimate the coefficients, $w_0$ and $w_1$, from the data observations under the assumption that the data-generating process is linear. For doing so, we minimise the least squares error function, i.e. $$ \begin{equation*} \boldsymbol{w}^\ast = \begin{bmatrix} w_0^\ast \\ w_1^\ast \end{bmatrix} = \arg\min_{w_0, w_1} \sum_{n=1}^N \left(y_n-\left(w_0+w_1x_n\right)\right)^2=\arg\min_{w_0, w_1} \left\|\boldsymbol{y} - \tilde{\boldsymbol{X}} \boldsymbol{w} \right\|_F^2. \end{equation*} $$ Solving this optimization problem, the optimal parameter estimate has the closed-form expression $$ \boldsymbol{w}^\ast = \left(\tilde{\boldsymbol{X}}^\top \tilde{\boldsymbol{X}}\right)^{-1} \tilde{\boldsymbol{X}}^\top \boldsymbol{y} $$ Based on the estimated parameters we can predict the value of an unobserved output $y^\ast$ from an observed measurement $x^*$ as $$ \begin{equation*} y_\ast = \left[\begin{array}{c} 1 & x_\ast \end{array} \right] \left[ \begin{array}{c} w^\ast_0 \\ w^\ast_1\end{array} \right] = \boldsymbol{x}_\ast^\top \tilde{\boldsymbol{w}}^\ast \end{equation*} $$

Part 2: Fitting non-linear data with a linear model - linear Regression in 1D ¶

Sometimes there are more complex relationships between the attributes and output. In order to capture more complex relationships we can include attributes that are specified transformations of existing attributes such as $\sqrt{x}$, $\log{(x)}$, $x^2$ and $x^3$.

We will presently consider the model

\begin{equation*} y_n = w_0 + \sum_{k=1}^{K} w_k x_n^k + \epsilon_n. \end{equation*}

You can see this as a generalisation of Part 1, where $K=1$.

The above model can again be written for all $N$ observations simultaneously in terms of vectors and matrices, i.e.

$$ \boldsymbol{y} = \left[\boldsymbol{1}\ \boldsymbol{x}^1\ \boldsymbol{x}^2\ \dots\ \boldsymbol{x}^{K}\right] \begin{bmatrix} w_0 \\ w_1 \\ w_2 \\ \vdots \\ w_{K} \end{bmatrix} + \boldsymbol{\epsilon} = \left[\boldsymbol{1}\ \boldsymbol{X}\right] \boldsymbol{w} + \boldsymbol{\epsilon} $$

where $\boldsymbol{x}^{k}=\left[ x_1^{k}, x_2^{k}, \dots, x_N^{k}\right]^\top$.

Part 4: Logistic regression on the Wine dataset ¶

Until now we have discussed the most simple linear model based on the squared error cost function. In the generalized linear model, we can also use other loss/cost functions as well as non-linear link functions.

It can be very useful to limit the possible outputs to the range $(0,1)$ if the outputs we wish to predict are binary. Predicting binary outputs is what we have previously referred to as binary classification and generalized linear models can thus both be used for regression and classification.

For outputs that are purely binary, $y\in\{0,1\}$, we can use the logistic function, $\sigma(x)=\frac{1}{1+\exp(-x)}$, as the non-linear link function. This function maps the output in the regression analysis to the range $(0,1)$ and ensures that $\sigma(x) = 1 - \sigma(x)$. You can read more about the logistic function here.

Classification with a likelihood function based on the Bernoulli distrbution and logistic link function is called logistic regression (for more information see here). We will return to the wine data and predict the type of wine using logistic regression. The model we consider is $$ p(y_n = 1 \mid \mathbf{x}_n, \mathbf{w})=\sigma\left(w_0+\sum_k w_k x_{n, k}\right)=\sigma\left( \mathbf{w}^T\mathbf{x} \right) $$ where $p(y_n = 1 \mid \mathbf{x}_n, \mathbf{w})$ is the likelihood of observing and outcome $y=1$ where we encode the of wine with 0 and 1 (Red: $y_n=1$ and White: $y_n=0$) given the model. We will say that a wine is Red with probability $\hat p_n$ and White with probability $1-\hat p_n$. where $\hat p_n=\sigma(w_0+\sum_k w_k x_{n,k})$.

This is quite math heavy and you are not expected to nessesarily understand everything except the conceptual meaning of what a gradient of a loss funciton is. If we consider the loss (derived from the likelihood) per observation which we need to optimize the the weights $\mathbf{\mathbf{w}}$: $e_n(\mathbf{w})= -\left>[y_n\log \hat p_n + (1-y_n)\log(1-\hat p_n)\right]$ and $E(\mathbf{w})=\frac{1}{N}\sum_{i=1}^N e_n(\mathbf{w}).$ where we use the shorthand notation $\hat p_n=p(y_n = 1 \mid \mathbf{x}_n)=\sigma( \mathbf{w}^T \mathbf{x}_n )$.

We exploit the chain rule and get $ \nabla_\mathbf{w} e_n(\mathbf{w})=\frac{\partial e_n}{\partial \hat p_n}\, \frac{\partial \hat p_n}{\partial f_n}\, \nabla_\mathbf{w} f_n. $ The individual terms can be extraced using basic calculus $$\small \frac{\partial e_n}{\partial \hat p_n} = -\left(y_n\frac{1}{\hat p_n}+(1-y_n)\frac{-1}{1-\hat p_n}\right) = -\frac{y_n}{\hat p_n}+\frac{1-y_n}{1-\hat p_n}. \qquad \frac{\partial \hat p_n}{\partial f_n} =\sigma'(f_n) =\sigma(f_n)\big(1-\sigma(f_n)\big) =\hat p_n(1-\hat p_n). \qquad \nabla_\mathbf{w} f_n=\nabla_\mathbf{w} (\mathbf{w}^\top \mathbf{x}_n)=\mathbf{x}_n. $$

We now get (and simplyfing a bit) $$ \nabla_\mathbf{w} e_n(\mathbf{w}) =\left(-\frac{y_n}{\hat p_n}+\frac{1-y_n}{1-\hat p_n}\right)\hat p_n(1-\hat p_n)\,\mathbf{x}_n. \qquad \left(-\frac{y_n}{\hat p_n}+\frac{1-y_n}{1-\hat p_n}\right)\hat p_n(1-\hat p_n) = -y_n(1-\hat p_n)+(1-y_n)\hat p_n = \hat p_n-y_n. $$

The final per-example gradient becomes $ \nabla_\mathbf{w} e_n(\mathbf{w})=(\hat p_n-y_n)\mathbf{x}_n =\Big(\sigma\!\big(f(\mathbf{x}_n;\mathbf{w})\big)-y_n\Big)\mathbf{x}_n. $ This is important, it tells you how much teh loss change if you change the weights based on a single observation. We are of course interested in how the loss changes across all the observations so we average the gradients accordingly (this is due to rules of differentiation) $$\small \nabla_\mathbf{w} E(\mathbf{w}) =\frac{1}{N}\sum_{i=1}^{N}\nabla_\mathbf{w} e_n(\mathbf{w}) =\frac{1}{N}\sum_{i=1}^{N}\Big(\sigma\!\big(f({\mathbf{x}}_n;\mathbf{w})\big)-y_n\Big)\mathbf{x}_n. $$

Of course we prefer the matrix form as it is more convinient: $$\small \nabla_\mathbf{w} E(\mathbf{w})=\frac{1}{N}{\mathbf{x}}^\top(\mathbf{\hat p} - \mathbf{y}). $$ where $\mathbf{y}$ are vectors of length N with the labeles and $\mathbf{\hat p}$ has the $p(y_n=1 \mid \mathbf{x}_n, \mathbf{w})$ values for all $N$ observations. This is the equation you need to implement!

Intuitively, we "walk downhill" on the loss landscape—taking steps in the direction of steepest decrease—until we reach (a) a valley where the loss is minimal, or (b) a point where further improvement becomes negligible.

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def p_y_given_w_and_x(w, X, y):
    p_y_is_one_given_x = sigmoid(X @ w)
    p = y*p_y_is_one_given_x + (1-y)*(1-p_y_is_one_given_x)
    return p

def loss_lr(w, X, y):
    es = -np.log(p_y_given_w_and_x(w, X, y))
    e = np.sum(es) / X.shape[0]
    return e

def loss_and_gradient_lr(w, X, y):

    g = (1/N) * X.T @ (p_hat - y)
